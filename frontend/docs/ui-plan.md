## How to use these references

1. **Screenshot & annotate**  
   Grab the specific components above (e.g., HackerRank’s playback timeline, CodeSignal’s file tree) and mark what you like: spacing, icon use, divider type.

2. **Map to your sitemap**  
   Drop each borrowed element into the corresponding Figma frame—see the “Which of your pages it inspires” column so every page gets at least one proven pattern.

3. **Tokenize, don’t copy pixel-for-pixel**  
   Re-skin colors & fonts with your Tailwind design tokens (e.g., `--primary`, `--bg`) so everything stays on-brand.

4. **User-test two styles**  
   Example: compare **HackerRank’s dense header** vs. **CodePad’s minimalist** one. Show both to a few dev friends; adopt whichever feels clearer.
